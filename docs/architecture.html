引擎类型API key默认模型别名说明
rapidocr本地 ONNX 无需 — rapid rapid-ocr rapidocr-onnx RapidOCR-onnxruntime,离线可用,中英文。适配 1.x 3-tuple / 1.4.x 2-tuple / 2.x dict。

请求处理流程

CLI / API / HTTP
   │  source(路径/URL)  +  strategy_name(可选)
   ▼
engine/inputs.py  load()  ──▶ PageImage(PIL 图像 + 尺寸)
   │
   ▼  attach_pil(page)
apply_strategy_preset(name)  ──▶ deepcopy config(一次性,不改 base)
   │
   ▼  build_pipeline(strategy)
   ├── strategy["bestof_mode"] 存在?
   │       ▼ 是
   │   BestofEngine(所有引擎各跑一次,串行)
   │       └─ 评分 smart / fastest / confidence / longest / fluency
   │              └─ 取最高分 ─▶ OCRResult
   │
   └── 否 ─▶ StrategyEngine(按 config.engines 顺序)
         │  ┌─ 尝试 engine[i] ─▶ recognise(page) ─▶ OCRResult
         │  │   retry_check(result)?
         │  │     ├─ 通过  ─▶ 返回(TimedOCR 计时)
         │  │     └─ 未通过 ─▶ 重试(≤ max_retries)─▶ 切换下一引擎
         │  │                    └─ cascade*: max_retries=0,跳过重试
         │  └─ 链耗尽 ─▶ 返回 ok 且文本最长的结果;皆无文本 ─▶ StrategyError (HTTP 422)
   ▼
OCRResult(text, regions, engine, model, elapsed_ms)
   │
   ▼
输出:JSON / Markdown / Text

配置与优先级

环境变量

变量用途
OPENAI_API_KEY通用 key,任意 OpenAI 兼容平台(所有 multimodal 条目共享)
OPENAI_BASE_URL共享端点 URL(不带序号,单平台够用)
OPENAI_BASE_URL_<N>第 N 条 multimodal 的端点,按 yaml 书写顺序编号,数量不限
JYKJ_OCR_MULTIMODAL_<N>_API_KEY第 N 条的独立 key(简写 MULTIMODAL_<N>_API_KEY 同样生效)
JYKJ_OCR_MULTIMODAL_<N>_MODEL第 N 条的模型 ID
JYKJ_OCR_CONFIG配置文件路径
JYKJ_OCR_PORTHTTP 服务端口

优先级(高 → 低)

1. 显式参数
     --engine / ocr(engine=...)
2. config/config.yaml
3. 环境变量(每个字段:先序号变量,再共享变量)
     OPENAI_BASE_URL_<N>  →  OPENAI_BASE_URL
     JYKJ_OCR_<NAME>_<N>_MODEL  →  JYKJ_OCR_<NAME>_MODEL
     JYKJ_OCR_<NAME>_<N>_API_KEY / <NAME>_<N>_API_KEY
     JYKJ_OCR_<NAME>_API_KEY / <NAME>_API_KEY  (按类型共享)
     OPENAI_API_KEY
4. 内置默认值(仅 model → PaddleOCR-VL-1.5)

方向与直觉相反,但这是代码实现:三个 resolved_* 都是「yaml 有值就用 yaml,留空才回退环境变量」。想让 OPENAI_BASE_URL 决定平台,把 config.yaml 里的 base_url 留空。 环境变量只在进程启动时读入,改完需重启服务。

HTTP 接口参考

方法路径说明异常 → HTTP
GET/health健康检查—
GET/engines可用引擎 + 实例级配置清单(每条 multimodal 各占一行,含 model/base_url 指纹)—
GET/config当前配置(不回显 key,仅 has_api_key)—

数据模型 (models.py)

OCRResult
  ├─ text:        str              # 全部文本(拼接)
  ├─ regions:     List[TextRegion] # 各文本块
  ├─ engine:      str              # 实际引擎
  ├─ model:       str              # 模型名(本地为空)
  ├─ elapsed_ms:  int              # 耗时
  ├─ width/height: int            # 页面尺寸
  └─ ok:          bool            # 是否有可用文本

TextRegion
  ├─ text:        str
  ├─ bbox:        BoundingBox | None
  ├─ confidence:  float           # [0,1]
  └─ engine:      str
  └─ from_parts(text, bbox, confidence=_UNSET, engine)
        # _UNSET 哨兵:调用方没传 confidence 时保留引擎自带分数,
        #              不静默抹平为 1.0

BoundingBox
  └─ x1,y1,x2,y2, confidence, width, height, center, area()
