引擎对照表

引擎类型API key默认模型别名说明
rapidocr本地 ONNX 无需 — rapid rapid-ocr rapidocr-onnx RapidOCR-onnxruntime,离线可用,中英文。适配 1.x 3-tuple / 1.4.x 2-tuple / 2.x dict。
siliconflow远程多模态 必需 PaddlePaddle/PaddleOCR-VL-1.5 sf silicon-flow silicon_flow 继承 MultimodalEngine,内置硅基流动默认 URL。不设 OPENAI_BASE_URL 时用内置默认。
multimodal远程多模态 必需 由 config 指定 multi openai openai-compat llm 通用 OpenAI 兼容端点,适配任意平台。base_url 留空时走 OPENAI_BASE_URL;两者皆无则报错(不静默回退硅基流动)。

请求处理流程

CLI / API / HTTP
   │  source(路径/URL)
   ▼
engine/inputs.py  load()  ──▶ PageImage(PIL 图像 + 尺寸)
   │
   ▼  attach_pil(page)
StrategyEngine(按 config.engines 顺序)
   │  ┌─ 尝试 engine[i] ─▶ recognise(page) ─▶ OCRResult
   │  │   retry_check(result)?
   │  │     ├─ 通过  ─▶ 返回(TimedOCR 计时)
   │  │     └─ 未通过 ─▶ 重试(≤ max_retries)─▶ 切换下一引擎
   │  └─ 链耗尽 ─▶ 返回 ok 且文本最长的结果;皆无文本 ─▶ StrategyError (HTTP 422)
   ▼
OCRResult(text, regions, engine, model, elapsed_ms)
   │
   ▼
输出:JSON / Markdown / Text

配置与优先级

环境变量

变量用途
OPENAI_API_KEY通用 key,任意 OpenAI 兼容平台
OPENAI_BASE_URL端点 URL(切换平台只改此两变量)
SILICONFLOW_API_KEY可选,覆盖 siliconflow 的 key
JYKJ_OCR_CONFIG配置文件路径
JYKJ_OCR_PORTHTTP 服务端口

优先级(高 → 低)

1. 显式参数
     --engine / ocr(engine=...)
2. 环境变量
     JYKJ_OCR_*
     JYKJ_OCR_<NAME>_API_KEY
     <NAME>_API_KEY
     OPENAI_API_KEY / OPENAI_BASE_URL
3. config/config.yaml
4. 内置默认值

HTTP 接口参考

方法路径说明异常 → HTTP
GET/health健康检查—
GET/engines可用引擎 + 配置顺序—
GET/config当前配置(不回显 key,仅 has_api_key)—
POST/config运行时覆盖(引擎/模型/策略),不重启ValueError → 400
DELETE/config清除运行时覆盖—
POST/ocr上传图片/PDF 识别(multipart)InputError→400 / EngineNotAvailable→422 / EngineError→502 / StrategyError→422
POST/ocr/text按图片 URL 识别(JSON)同上

POST /ocr form 字段

字段必填说明
file✅图片或 PDF
engine—强制引擎
model—覆盖模型(仅远程引擎)
prompt—覆盖 prompt(仅远程引擎)
strategy—JSON 字符串,临时策略
max_pages—PDF 页数上限
dpi200PDF 渲染 DPI
formatjsonjson / text / markdown

数据模型 (models.py)

OCRResult
  ├─ text:        str              # 全部文本(拼接)
  ├─ regions:     List[TextRegion] # 各文本块
  ├─ engine:      str              # 实际引擎
  ├─ model:       str              # 模型名(本地为空)
  ├─ elapsed_ms:  int              # 耗时
  ├─ width/height: int            # 页面尺寸
  └─ ok:          bool            # 是否有可用文本

TextRegion
  ├─ text:        str
  ├─ bbox:        BoundingBox | None
  ├─ confidence:  float           # [0,1]
  └─ engine:      str
  └─ from_parts(text, bbox, confidence=_UNSET, engine)
        # _UNSET 哨兵:调用方没传 confidence 时保留引擎自带分数,
        #              不静默抹平为 1.0

BoundingBox
  └─ x1,y1,x2,y2, confidence, width, height, center, area()
