jykj_ocr

多引擎 OCR 服务 —— 本地 RapidOCR(离线)+ 多模态 OCR 大模型(硅基流动 / 任意 OpenAI 兼容端点),策略层重试编排,提供 CLI、Python API 与 FastAPI HTTP 接口。

查看架构图 流程图 用户手册 GitHub 仓库

三引擎对照

引擎类型API Key默认模型
rapidocr本地 ONNX无需—
siliconflow远程多模态必需PaddlePaddle/PaddleOCR-VL-1.5
multimodal远程多模态必需由 config 指定(回退 PaddleOCR-VL-1.5)

远程引擎统一走 OpenAI 兼容协议(POST /chat/completions),只依赖 requests,不引入 openai SDK。

核心特性

统一端点

设一对 OPENAI_API_KEY/OPENAI_BASE_URL 即可指向任意平台,换平台不改代码。

策略重试

按引擎顺序尝试,支持 no_text/low_confidence 重试判定与自动切换。

运行时配置

POST /config 热改模型/引擎/策略,不重启;线程安全,不回显 key 明文。

惰性注册

import jykj_ocr 不加载 PIL/rapidocr/openai,引擎按需 import。

快速开始

# 安装(自包含 requirements.txt)
pip install -r requirements.txt

# 配置远程引擎(换平台只改这两个变量)
export OPENAI_API_KEY=sk-xxx
export OPENAI_BASE_URL=https://api.siliconflow.cn/v1

# CLI 识别
python -m jykj_ocr image.png --engine siliconflow --format json

# 启动 HTTP 服务
python -m jykj_ocr serve --port 8000

HTTP 接口一览

方法路径说明
GET/health健康检查
GET/config当前配置(不回显 key)
POST/config运行时覆盖配置
POST/ocr上传图片/PDF 识别(multipart)
POST/ocr/text按图片 URL 识别(JSON)
